# Poker Timer Landing Page

Landing page for a Poker Timer app built with React and Next.js.

The website is available at [https://poker-timer.toondeboer.com](https://poker-timer.toondeboer.com).

## Tech Stack
- React 
- Next.js
- TypeScript
- Tailwind CSS
- Vercel for hosting

## Getting Started
Run locally:
```bash
    npm run dev
```
